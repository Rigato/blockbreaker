# Arquivo histórico

Documentos mantidos para consulta e rastreabilidade. **Não são a fonte atual.**
Para iniciar uma nova sessão, use os documentos da raiz de `docs/` e o handoff
vigente.

| Pasta | Conteúdo |
|---|---|
| `handoffs/` | handoffs anteriores (pós-MVP e v0.3.0) |
| `plans/` | planos de implementação já concluídos: MVP, v0.2.0, Endless, revisão visual v0.4.0 e o plano de baixa fricção (absorvido pelo guia de publicação) |
| `qa/` | relatórios de QA, device matrix, performance e baseline automatizado do MVP |
| `release/` | revisão G7 e validação técnica do pacote `0.1.0-mvp` |

O GDD atual, o gap analysis, o handoff vigente, o guia único de publicação
(`docs/spec-tecnica-publicacao.md`) e os documentos operacionais de release
continuam em `docs/`. O antigo `plano-baixa-fricao.md` foi arquivado em
`plans/` e seu conteúdo estratégico foi absorvido pelo guia.
